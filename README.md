# Smart Parking Management System

## Description
A web-based application that allows drivers to locate and reserve 
available parking spaces in real time, while admins manage slots 
and monitor occupancy.

## Team Members
- Nursena Idrizi (Student ID: 131666)

## Technologies Used
- Frontend: React.js, HTML5, CSS3, Bootstrap 5
- Backend: Node.js, Express.js
- Database: MySQL / PostgreSQL
- Authentication: JWT, bcrypt
- ORM: Sequelize
- Testing: Jest, Supertest, Postman
- Version Control: Git + GitHub

## Features
- User registration and secure login (JWT-based)
- Real-time parking slot availability tracking
- Online reservation creation, modification, and cancellation
- Payment processing integration
- Admin dashboard for slot/user management and reporting
- Email/in-app notifications for booking confirmations

## Software Architecture
3-Tier MVC Architecture:
- Presentation Layer: React.js SPA
- Application Layer: Node.js + Express.js REST API
- Database Layer: MySQL/PostgreSQL via Sequelize ORM

## Project Structure
- `/src` - Source code
- `/docs` - Documentation (report + presentation)
